# Contributing

Thanks for helping build **Nuvio IPTV**, the Apple TV app that brings the Live TV features of [Nuvio + IPTV](https://github.com/homelessbrian/NuvioPlusIPTV) to [NuvioTVOS](https://github.com/bobsupra/NuvioTVOS).

## What's welcome

- **Live TV features from the roadmap.** See *Feature status* in the [README](./README.md#feature-status). Open an issue or comment on an existing one before you start, so two people don't build the same thing.
- **Bug fixes**, especially in Live TV / IPTV.
- **Translations** of the Live TV strings (`livetv_*` keys).
- **Build / CI and docs** improvements.

Changes to the upstream app itself (player, catalogs, add-ons and so on) are better sent to [NuvioTVOS](https://github.com/bobsupra/NuvioTVOS) directly. This fork then picks them up when it syncs with upstream.

## You don't need a Mac

1. Fork this repository and push your branch.
2. GitHub Actions ([`build-ipa.yml`](.github/workflows/build-ipa.yml)) builds an unsigned IPA for every push. Find it under **Actions → your run → Artifacts**.
3. Sideload it to an Apple TV to test (Sideloadly, AltStore/SideStore, atvloadly, …).

With a Mac you can build locally:

```bash
mise install                    # pinned Tuist version
(cd tvosApp && tuist generate)  # writes NuvioTV.xcworkspace
./scripts/build-ipa.sh          # unsigned IPA in ./build-ipa
```

The Xcode project is generated by [Tuist](https://tuist.dev) from [`tvosApp/Project.swift`](./tvosApp/Project.swift). Don't commit the generated `.xcodeproj` / `.xcworkspace`. New Swift files under `tvosApp/NuvioTV/Sources/` are picked up automatically.

For on-device signing, copy `tvosApp/Configurations/Signing.local.example.xcconfig` to `Signing.local.xcconfig` and set your own Team ID. See [tvosApp/Configurations/README.md](./tvosApp/Configurations/README.md).

## Code guidelines

- **Keep Live TV code in its own folders:** `tvosApp/NuvioTV/Sources/Core/LiveTV/` (data, API clients, storage) and `tvosApp/NuvioTV/Sources/UI/LiveTV/` (views).
- **Touch upstream files as little as possible.** Every line changed in an upstream file can conflict when this fork syncs with NuvioTVOS. Prefer small hooks, like a new tab or a callback, over rewriting existing code.
- **Don't edit `Vendor/` or `MPVKit/`.** These are vendored upstream dependencies.
- **Secrets go into the Keychain.** IPTV passwords never go into `UserDefaults`, sync payloads, logs or bug-report exports. Follow `XtreamAccountStore` / `SMBCredentialStore`.
- **Strings:** use `L10n.string("livetv_…", fallback: "English text")`.
- **Porting from NuvioPlusIPTV:** it's GPL-3.0 like this project, so porting its logic is fine. Mention the original file in a comment or your PR (e.g. `livetv/data/M3uParser.kt`).
- **Never commit real playlist URLs, server addresses, usernames or passwords**, not even in tests or screenshots.

## Pull requests

- **One feature or fix per PR.** Smaller PRs are reviewed faster.
- **Fill in the PR template.** A check verifies that it's filled in.
- **The IPA build must pass.** The `Build unsigned IPA` check runs automatically.
- **Say how you tested.** For example "Apple TV 4K, tvOS 26.1, Xtream provider" or "only built, not tested on a device". Untested PRs are fine, just be honest about it.
- **UI changes:** add a screenshot or a short video (photos of the TV are fine). Blur channel names or logos if you prefer.

## Bug reports

Use the issue templates. For Live TV problems, say whether you use Xtream or M3U and whether the problem happens with every channel or only some. **Don't post your server address, username, password or playlist link.**
